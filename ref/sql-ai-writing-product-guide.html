SQL with AI — product notes

SkylineAI / sqllens.ai turns natural language in .sql files into executable SQL via CodeLens, commands, and the AI Assist panel. This page summarizes recent editor behavior and block-comment workflows; the canonical reference remains the unified guide.

Full documentation. Open skyline-product-guide.html#ai-start for the complete tree (prompt shapes, CodeLens, settings, providers) and #ai-syntax for directive tables.

What’s new (editor)

The following behaviors apply to the Skyline SQL completion provider (IntelliSense-style list from the extension), not necessarily to VS Code’s generic word suggestions.

  • No SQL autocomplete inside comments. Suggestions are suppressed when the caret is inside:
    • a block comment (/* … */),
    • a line comment after --,
    • a MySQL-style line comment after #.
    String and backtick literals are respected so delimiters inside quotes do not flip the scanner into “comment” mode. This keeps long @AI prompt text and notes from being flooded with keyword/table popups.
  • Optimizer webview Monaco editor. The same rule is applied to the embedded SQL editor in the Query Optimizer workbench, so behavior matches the main .sql editor for that surface.

Implementation: src/provider/parser/sqlBlockCommentAtPosition.ts (isPositionInsideSqlComment), src/provider/complete/completionProvider.ts, and src/provider/queryOptimizerWorkbench.ts (Monaco provider).

Block-comment @AI (quoted prompt + generated SQL)

You can keep the natural-language request inside a SQL block comment with a quoted @AI directive. Generated SQL is placed after the closing */, so the prompt stays separate from executable code. Expanding a trailing @ai (or a line that is only @) can wrap your text in this form automatically. 

/* @AI "
List active employees in Engineering hired after 2023-01-01.
" */
SELECT e.emp_no, e.first_name, e.last_name
FROM employees e
JOIN dept_emp de ON de.emp_no = e.emp_no AND de.to_date = '9999-01-01'
JOIN departments d ON d.dept_no = de.dept_no
WHERE d.dept_name = 'Engineering' AND e.hire_date > '2023-01-01';
  • Regenerate. Editing the text between the quotes and using Generate again updates the SQL span tied to that block (prompt ↔ query binding is tracked for the pair).
  • Placeholder line. A faint in-editor placeholder can appear for empty directive text until you type a real prompt (stripped before the model sees it).

Reference: src/provider/parser/sqlBlockAnalyzer.ts, src/provider/parser/aiSqlPromptQueryBinding.ts, src/service/ai/aiCommands.ts.

Prompt ↔ SQL pairing (high level)

For block-comment directives, the extension resolves which generated SQL range belongs to which prompt (including SQL-only output after */ and legacy prompt-header styles). That keeps Regenerate / replace ranges stable while you edit multi-statement scripts.

Step-by-step algorithm: see the module doc at src/provider/parser/aiSqlPromptQueryBinding.ts.
