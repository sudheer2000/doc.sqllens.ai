    What SQLLens is

    SQLLens is a database workspace that lives in your editor. It connects to MySQL, MariaDB, PostgreSQL, and SQLite, gives you a fast SQL editor with autocomplete and CodeLens, a drag‑and‑drop query builder, a schema designer, and performance tools — Query Optimizer (QO), Slow Query Log Analyzer (QLA), Performance Monitor (PM), and Query Profiler. AI features can generate, fix, and explain SQL; MCP lets agents query through your saved profiles.

    Query Optimizer — AI index advisory

    The Query Optimizer workbench includes Index Strategy Studio on the Analyze panel: rule-based Index Engine suggestions, one-click AI Advisor (Auto), and on MySQL/MariaDB 3 AI compare (LLMs) — run up to three models in parallel, rank by consensus, and create the winning index DDL.
