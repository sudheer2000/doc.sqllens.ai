    Get started

    Install SQLLens.AI (SQLLens.AI on the Marketplace, publisher skylineai, extension id skylineai.sqllens), open the sidebar, connect a database, and run SQL from any .sql file.

    Install the extension

    Works in Visual Studio Code and editors with a compatible VS Code runtime (e.g. Cursor).

    1. Open the Extensions view (Ctrl+Shift+X on Windows/Linux, ⌘+Shift+X on macOS).
    2. Search for SQLLens.AI and install it.
    3. Reload the editor if prompted.

    Open the sqllens.ai sidebar

    Click the SQLLens.AI icon in the activity bar to open the sidebar. You'll see the connections explorer at the top and panels for results, favorites and status below the editor.

    Tip

    Pin the SQLLens.AI views to the secondary side bar if you want connections visible while writing code.

    Credentials & security

    Connection passwords are stored in VS Code’s Secret Storage. You can use SQLLens.AI fully offline for MySQL/MariaDB work—disable cloud-backed features via skyline-mysql.skylineApi.enabled if your policy requires no sqllens.ai sign-in. See Cloud account → offline mode and Connect database for TLS and SSH tunnels.
