    Schema & database objects

    Create, alter and drop databases, tables, views, routines and triggers from the tree.

    Overview

    Right‑click any node in the explorer to see the actions available for that object. Most actions open a wizard; the wizard preview shows the SQL it will execute.

    Databases

    Create, drop or alter a database (charset, collation). The wizard offers Generate SQL only if you'd rather review and run it manually.

    Tables & designer

    The Table designer lets you edit columns, keys and indexes side‑by‑side. Add a row to insert a column; the SQL preview tab shows the resulting ALTER TABLE.

    Views, routines & triggers

    Create views, stored procedures, functions and triggers from the tree. Routine and trigger templates include a DELIMITER block so they run as a single statement (see DELIMITER note).

    Users & privileges

    If your role can manage users, the Users node lets you create accounts and grant privileges per database or per object. Grants are visible inline next to each user.
