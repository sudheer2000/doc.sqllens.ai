    Advanced: mock & diagnostics

    Optional tools for testing and troubleshooting. Not part of the day‑one learning path.

    Overview

    These tools help reproduce issues and validate fixes. Reach for them when you're debugging — not when you're learning the product.

    Mock JSON runner

    Place a mock.json file in your workspace describing requests and expected results, then run SQL: Run Mock JSON. SQLLens.AI validates each case and reports diffs.

    Mock table generator

    Run SQL: Generate Mock Table to create a sample table populated with realistic test data. Useful for tutorials, demos and reproducible bug reports.

    Diagnostic queries

    Run mysql.diagnostics.show to open the diagnostics palette — the same one available from Performance Monitor.
