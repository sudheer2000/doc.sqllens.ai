    Data import, export & schema tools

    Move data and schema between databases — bulk import/export, schema sync, documentation, and script execution.

    Overview

    Use these pipelines when you need to move more than a few rows. For ad‑hoc work, the SQL editor is usually faster.

    Import & export data

    Right‑click a table and choose Import or Export. Supported formats include CSV, JSON, SQL inserts and XLSX. The wizard previews the first rows so you can map columns.

    Schema sync / compare

    Pick a source and target connection, run the comparison, then apply selected differences. Each difference shows the SQL that will run.

    Generate documentation

    Produce an HTML or Markdown reference of databases, tables, columns, keys and routines, ready to share or commit.

    Copy structure & execute script

    Copy a table's DDL to another connection, or execute a multi‑statement script from disk against the active connection with progress reporting.
