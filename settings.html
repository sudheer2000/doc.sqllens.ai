    Settings reference

    Every SQLLens.AI configuration key — grouped, defaulted, and cross‑linked to the feature it affects.

    How to open settings

    Open the VS Code Settings UI (Ctrl+, on Windows/Linux, ⌘+, on macOS). Search for skyline-mysql — every key below appears in the Settings editor under the SQLLens.AI contribution, grouped the same way you see it in the UI.

    Note

    Defaults and enums may evolve with releases; use the in-editor settings UI after search for authoritative enum lists.
